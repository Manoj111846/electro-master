# 🛒 Electro Master -- E-Commerce Website

A responsive **Electro Master** e-commerce website built using HTML,
CSS, JavaScript, and web assets.\
The project provides a clean online shopping interface for browsing
electronics such as laptops, smartphones, cameras, and accessories.

## 🌐 Live Website

**GitHub Pages:**\
https://manoj111846.github.io/electro-master/

## 📌 Project Overview

Electro Master is a front-end e-commerce website designed to demonstrate
how a modern electronics shopping website can be structured.

The website includes:

-   🏠 Home page
-   🛍️ Product listing page
-   📦 Product details page
-   🛒 Checkout page
-   📄 Regular/blank page
-   🔎 Product search interface
-   ❤️ Wishlist and cart interface
-   ⭐ Product ratings and reviews
-   📧 Newsletter subscription section
-   📱 Electronics categories
-   🖼️ Product images and supporting assets

## 🚀 How to Run Locally

1.  Download or clone the repository.
2.  Open the project folder.
3.  Open `index.html` in a web browser.

No backend server is required for the basic front-end version.

## ☁️ GitHub Pages Deployment

The website is hosted using **GitHub Pages**.

Deployment configuration:

-   **Repository:** `Manoj111846/electro-master`
-   **Branch:** `main`
-   **Folder:** `/ (root)`
-   **Hosting:** GitHub Pages

Whenever updated files are pushed to the `main` branch, GitHub Pages can
rebuild the website.

## 🔄 Update the Website

After making changes:

``` bash
git add .
git commit -m "Update Electro Master website"
git push
```

GitHub Pages will then deploy the updated version.
