# 🛒 Electro Master — E-Commerce Website

A clean and responsive **Electro Master E-Commerce Website** built using **HTML, CSS and JavaScript**.  
The project provides a modern online-shopping interface for browsing electronic products, viewing product details, and completing checkout.

## 🌐 Live Demo

**GitHub Pages:**  
https://manoj111846.github.io/electro-master/

## 📌 Project Overview

Electro Master is a front-end e-commerce website designed for an electronics store. It includes product browsing, product details, shopping/checkout pages, category navigation, and responsive UI sections.

### ✨ Main Features

- 🏠 Home page with featured products
- 💻 Laptop, smartphone, camera and accessory categories
- 🛍️ Product listing page
- 🔎 Product details page
- ⭐ Product ratings and reviews section
- 🛒 Add-to-cart interface
- 💳 Checkout page with billing and shipping sections
- 📱 Responsive and user-friendly layout
- 📰 Newsletter subscription section
- 🧭 Navigation menu and category links

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Front-end interactions
- **Git & GitHub** — Version control and hosting
- **GitHub Pages** — Deployment

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use **VS Code Live Server** for a better development experience.

## ☁️ GitHub Pages Deployment

This project can be hosted directly using GitHub Pages.

1. Push the project to GitHub.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the `main` branch.
5. Select `/ (root)`.
6. Click **Save**.
7. Open the generated GitHub Pages URL.
